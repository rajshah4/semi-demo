# Sync FIFO Example Work Cell

This folder contains the bundled RTL example used by the Foundry IT workflow:

- `fifo_request.md` - system-of-record style request/spec.
- `sync_fifo.sv` - intentionally incomplete starter RTL.
- `sync_fifo_tb.sv` - simple testbench for validation.

OpenHands automations use this as a compact work cell for showing model routing,
ChipCraftX first-draft RTL generation, EDA validation, PR evidence, and human
review gates.
