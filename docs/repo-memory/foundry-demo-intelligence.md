# Foundry Demo Intelligence

## Audience

Foundry IT, semiconductor platform teams, infrastructure teams supporting RTL/design engineers, and enterprise AI stakeholders.

## What They Care About

- air-gapped or private execution
- approved models and approved toolchains
- audit trails
- license and PDK constraints
- model flexibility
- deterministic validation
- repeatable workflows
- integration with GitHub, Jira, CI, and internal portals

## Message To Avoid

"The model writes correct Verilog by itself."

## Message To Use

"OpenHands coordinates models and tools to create a controlled engineering workflow. The EDA tools decide what passes."
